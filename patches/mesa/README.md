Patch [0085](0085-grate-report-refused-programs-to-the-state-tracker.patch) (after 0084): grate: report refused programs to the state tracker. A fragment or vertex program the compiler refuses (KWin's colour-pipeline shader, `scalar register bank exhausted`) returned NULL from `create_fs_state`/`create_vs_state` without a message, so the GL program still linked and every draw with it was skipped silently. With `report_compile_error` set (the state tracker sets it at link time) the driver now fills `error_message` like i915 and r300, the link fails and applications fall back to a simpler shader (KWin: `Falling back to shaders without TransformColorspace`). A skipped draw is logged with `GRATE_DEBUG=unimplemented`. Checked on the tablet: 7 colour-pipeline variants fail to link and KWin falls back, no skipped draw, no gr3d reset.



Patch [0084](0084-grate-vertex-programs-ARL-needs-r0-TRUNC-into-ARL-MA.patch) (after 0083): grate: vertex programs: ARL needs r0, TRUNC into ARL, MAD fusion. `ARL` did not load the address register with r63 or r1 as its destination (a first index in r1 read slot 0, the same index in r0 worked); NVIDIA's `ARL` always writes r0, and the 0082 rule "the register it reads" had only held where that was r0. A program with an `ARL` reserves r0 (temporaries start at r1), the source lane is the address lane and the reads select it. Peepholes, each for straight-line code and a value that is dead afterwards, never on `precise` instructions: the `TRUNC` goes when an `ARL` reads it (NVIDIA: `MAD`, `ARL`), `MUL` + `ADD` becomes `MAD`, the exact `x * 0.0 + x` pair NIR leaves after a varying goes, self moves, the copy in front of an `ARL`, two `ARL`s from one register become one `ARL r0.xy`, a `MOV` is propagated into its reader and `MOV out = t` into the writer of `t`. Counts against NVIDIA: `mad-fuse` 3/3, `mad-fuse-neg` 3/3, `mad-keep` 4/4, `idx-attr` 4/4, `idx-two-attr` 8/8, `idx-offset` 8/9, `idx-two` 8/7, `mad-chain` 6/5, `mad-fetch` 4/3. Checked on the tablet: `grate-vertex-ops-test` 84 of 84 (also with every peephole off), the other `grate-*-test` programs unchanged, a full glmark2 run without vertex messages and with identical fragment layouts (score 249 against 232, one run each).
